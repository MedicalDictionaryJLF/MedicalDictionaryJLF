# Patient Trainer standalone v3

This build stays separate and is **not merged into the full Medical Dictionary app**.

## Fixes in this version
- corrected anterior **auscultation** point placement
- corrected anterior **percussion** point placement by retuning shared lung and abdominal coordinates
- refined standard cardiac auscultation areas (aortic, pulmonic, Erb's, tricuspid, mitral)
- refined anterior lung comparison fields
- refined posterior lung comparison fields
- kept the photorealistic **posterior view** active in the standalone trainer
- preserved the separate standalone Patient Trainer packaging only
